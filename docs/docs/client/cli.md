After installing Avala within your Python virtual environment, you will also have access to a CLI utility `avl`. This page lists all the commands that you can use. Use it for reference.

## `avl init`

initializes avala workspace

## `avl run`

```
avl run [exploit_alias]
```

## `avl services`

prints out services

## `avl flag_ids`

```
avl flag_ids [service_name] [target_name] [tick_index]
```

all are optional ^

## `avl submit`

```
avl submit
Paste content containing the flags:
```
